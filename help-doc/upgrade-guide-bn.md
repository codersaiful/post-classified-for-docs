# আপগ্রেড গাইড - BizzDocMaker 2.0

## ভূমিকা

BizzDocMaker 2.0 একটি বড় আপডেট যা প্লাগিনটিকে সম্পূর্ণভাবে নতুন করে তৈরি করা হয়েছে। এই ডকুমেন্টে আপগ্রেড প্রক্রিয়া এবং নতুন ফিচার সম্পর্কে বিস্তারিত তথ্য রয়েছে।

## সিস্টেম প্রয়োজনীয়তা

### পূর্বের সংস্করণ (1.x)
- PHP: 5.6+
- WordPress: 4.0+

### নতুন সংস্করণ (2.0)
- PHP: 7.0+ (প্রয়োজনীয়)
- WordPress: 5.0+ (প্রয়োজনীয়)

## আপগ্রেড করার আগে

### ১. ব্যাকআপ নিন
```
- পূর্ণ সাইট ব্যাকআপ নিন
- ডাটাবেস ব্যাকআপ নিন
- প্লাগিন ফাইল ব্যাকআপ নিন
```

### ২. সিস্টেম চেক করুন
```
- PHP ভার্সন চেক করুন: Settings > Site Health
- WordPress ভার্সন চেক করুন
- সক্রিয় প্লাগিন তালিকা তৈরি করুন
```

### ৩. টেস্ট এনভায়রনমেন্ট (ঐচ্ছিক)
```
- স্টেজিং সাইটে প্রথমে আপগ্রেড করুন
- সব ফিচার টেস্ট করুন
- সমস্যা থাকলে সমাধান করুন
```

## আপগ্রেড প্রক্রিয়া

### পদ্ধতি ১: WordPress Admin থেকে

1. **Dashboard যান**
   - Plugins > Installed Plugins

2. **আপডেট নোটিশ দেখুন**
   - BizzDocMaker এর পাশে "Update Now" দেখবেন

3. **আপডেট করুন**
   - "Update Now" ক্লিক করুন
   - অপেক্ষা করুন আপডেট সম্পন্ন হওয়া পর্যন্ত

4. **সফলতা যাচাই করুন**
   - Version 2.0.0 দেখা যাচ্ছে কিনা চেক করুন

### পদ্ধতি ২: ম্যানুয়াল আপগ্রেড

1. **পুরাতন প্লাগিন ডিঅ্যাক্টিভেট করুন**
   ```
   Plugins > Deactivate BizzDocMaker
   ```

2. **পুরাতন ফাইল মুছে ফেলুন**
   ```
   FTP/File Manager থেকে:
   /wp-content/plugins/post-classified-for-docs/
   ```

3. **নতুন ফাইল আপলোড করুন**
   ```
   নতুন ZIP ডাউনলোড করুন
   আপলোড করুন এবং আনজিপ করুন
   ```

4. **প্লাগিন অ্যাক্টিভেট করুন**
   ```
   Plugins > Activate BizzDocMaker
   ```

## আপগ্রেড পরবর্তী পদক্ষেপ

### ১. ওয়েলকাম স্ক্রিন দেখুন

আপগ্রেড করার পর স্বয়ংক্রিয়ভাবে ওয়েলকাম স্ক্রিনে রিডিরেক্ট হবে। এখানে নতুন ফিচার সম্পর্কে তথ্য পাবেন।

### ২. সেটিংস কনফিগার করুন

```
BizzDocMaker > Settings
```

**প্রস্তাবিত সেটিংস:**
- Default Template: list
- Enable Caching: on (পারফরম্যান্সের জন্য)
- Posts Per Page: -1 (সব দেখান)

### ৩. শর্টকোড পরীক্ষা করুন

**পুরাতন শর্টকোড (এখনও কাজ করে):**
```
[WPPCD_Post]
[WPPCD_Post taxs='1,2,3']
```

**নতুন শর্টকোড (প্রস্তাবিত):**
```
[bizzdocmaker]
[bizzdocmaker template="grid"]
```

### ৪. ক্যাশ পরিষ্কার করুন

```
- WordPress ক্যাশ পরিষ্কার করুন
- ব্রাউজার ক্যাশ পরিষ্কার করুন
- CDN ক্যাশ purge করুন (যদি থাকে)
```

### ৫. পেজ পরীক্ষা করুন

যেসব পেজে শর্টকোড আছে সেগুলো চেক করুন:
```
- Frontend দেখুন
- সব টেমপ্লেট পরীক্ষা করুন
- মোবাইলে দেখুন
```

## নতুন ফিচার ব্যবহার করা

### ১. নতুন টেমপ্লেট ব্যবহার

**Grid টেমপ্লেট:**
```
[bizzdocmaker template="grid" columns="3"]
```

**Accordion টেমপ্লেট:**
```
[bizzdocmaker template="accordion"]
```

**Table টেমপ্লেট:**
```
[bizzdocmaker template="table"]
```

### ২. অ্যাডমিন ফিচার

**সেটিংস পেজ:**
```
BizzDocMaker > Settings
```

**হেল্প ও সাপোর্ট:**
```
BizzDocMaker > Help & Support
```

**Dashboard Widget:**
```
Dashboard এ যান এবং স্ট্যাটিস্টিক্স দেখুন
```

### ৩. পোস্ট অর্ডারিং

**এডিটরে:**
1. যেকোনো পোস্ট Edit করুন
2. "BizzDocMaker - Post Order" মেটা বক্স দেখুন
3. Order নম্বর সেট করুন (যেমন: 1, 2, 3...)
4. Update/Publish করুন

## সমস্যা সমাধান

### সমস্যা: শর্টকোড কাজ করছে না

**সমাধান:**
1. প্লাগিন সক্রিয় আছে কিনা চেক করুন
2. WordPress এবং PHP ভার্সন চেক করুন
3. ক্যাশ পরিষ্কার করুন
4. থিম কনফ্লিক্ট চেক করুন

### সমস্যা: স্টাইলিং ভেঙ্গে গেছে

**সমাধান:**
1. ব্রাউজার ক্যাশ পরিষ্কার করুন (Ctrl+Shift+R)
2. WordPress ক্যাশ পরিষ্কার করুন
3. CDN ক্যাশ purge করুন
4. CSS ফাইল রিজেনারেট করুন

### সমস্যা: Admin পেজ দেখাচ্ছে না

**সমাধান:**
1. User capability চেক করুন (manage_options থাকতে হবে)
2. প্লাগিন ফাইল permission চেক করুন
3. Error log দেখুন
4. প্লাগিন deactivate এবং activate করুন

### সমস্যা: PHP Error দেখাচ্ছে

**সমাধান:**
1. PHP ভার্সন 7.0+ আছে কিনা চেক করুন
2. Error log চেক করুন
3. অন্য প্লাগিন deactivate করে দেখুন
4. Support ফোরামে সাহায্য চান
